Detection is off

Mooring is not running detection rules on this host. Detection reads the security logs, so both need to be on: set security_logs.detection.enabled: true in /etc/mooring/config.yaml (with security logs not turned off) and restart Mooring. If it is already on, Mooring's startup log says why detection did not start.

security_logs:
  detection:
    enabled: true

Reference: docs/security-logs.md
