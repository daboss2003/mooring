Log patterns are off

Mooring is not grouping log lines into patterns on this host. To turn them on, set security_logs.detection.patterns.enabled to true in /etc/mooring/config.yaml and restart Mooring. If it is already true, Mooring's startup log says why log patterns did not start.

security_logs:
  detection:
    patterns:
      enabled: true
