Preview environments (a deploy per pull request)

When on, a signed GitHub pull_request webhook spins up a throwaway copy of this app for each PR — its own subdomain, HTTPS from your base_domain wildcard — and tears it down when the PR closes. A preview inherits this app's env & secrets, runs isolated, and can never affect production.
