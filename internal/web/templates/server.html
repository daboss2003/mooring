Docker accumulates dangling build images and old build cache as your apps redeploy — usually the main thing that fills a server. Mooring reclaims this automatically when disk gets tight (the server.disk_gc_threshold, default 75%), and you can reclaim it right now. Only unused garbage is removed — never a running app, a tagged image, or any data.
