Automated response is not running

Mooring is not running automated response on this host. It runs with detection; set security_logs.response.mode to recommend or enforce in /etc/mooring/config.yaml to have it recommend or make blocks and sign-outs, then restart Mooring. If detection is on, Mooring's startup log says why automated response did not start.

security_logs:
  response:
    mode: recommend   # or enforce
